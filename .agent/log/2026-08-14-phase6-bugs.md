## Bug 1 — the two ReferenceError crashes (App.jsx:1275, Tasks.jsx:198)

**1a — `App.jsx:1275` (`onOpenDosing`).** Traced per the routine's own
instruction rather than assumed: `Dashboard.jsx:60`'s own `goTo` maps
`dest.tab !== "param"` to `onGoTab(dest.tab, dest.key)`, and App.jsx's own
`onGoTab={(t) => setTab(t)}` (passed to `Dashboard`) already drops the `key`
argument for every non-"param" tab — so the `key` `onOpenDosing` receives
(`ReadingConfirmation.jsx:567`'s `onOpenDosing(def.key)`) was already inert
everywhere else `goTo`-style navigation happens in this app; `DosingWizard`
(`App.jsx:1219-1229`) takes no key/highlighted-param prop at all. Fix matches
that existing pattern exactly: `onOpenDosing={() => setTab("dosing")}` — no
local `goTo` helper needed, since there was never a second consumer of the
key to justify one.

**1b — `Tasks.jsx:198` (`ReminderSheet`'s `onComplete`).** Confirmed
`ReminderSheet`'s `onComplete` contract is `(id) => void` (`backup.jsx:438`,
`onClick={() => onComplete(rem.id)}`) — exactly what `completeReminder`
(`App.jsx:873`, passed in as `Tasks`'s `onMarkDone`) already is. Fix:
`onComplete={(id) => { onMarkDone(id); closeSheet(); }}`.
