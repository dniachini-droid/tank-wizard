   unchanged — steady-off exists for exactly that state). If Dan reads blue
   as calm, it is a one-line change to TONE_TIER.

## In plain terms

The steadiness note no longer uses "drifting", a word the rest of the app
uses for the opposite situation — it says "unsettled". However steady your
tank has been, if the last test is at a level that needs attention the note
can no longer show in a calm colour, and it tells you the level first and
the steadiness second. And where the app has no yardstick for steadiness it
now says so instead of grading you against nothing. A build check enforces
all three from now on, so they cannot quietly rot.
