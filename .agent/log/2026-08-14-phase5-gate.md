## 05:10-06:40 — porting the 14 scripts

Wrote `scripts/verify/util.mjs` (shared helpers: source file listing, import
resolution, bracket-depth matching) then one script per surviving checker.
Tested each against the real tree as it was written, not just against
scratch fixtures — this caught real bugs in the checkers themselves before
they could ship as false positives or false negatives:

- `linkcheck.mjs` (validate.js's surviving half): first draft used
  `[^)]*`-style regexes for parameter lists, same as the original, and
  missed `Dashboard`'s props entirely because one default value
  (`setRemWindow = () => {}`) contains its own parens — everything after it
  in the same destructure silently vanished from the scan. Replaced with a
  bracket-depth matcher (`matchBracket` in util.mjs). A second pass to strip
  JSX prose text (so "Report photo (optional)" doesn't read as a call to
  `photo`) was tried as a general `>...<` stripper and reverted after it
  started reporting `useEscape`, `dosePlausible` and `CompletionCalendar` —
  all real, all declared — as undefined, because `=>` and ordinary `>`/`<`
  comparisons are indistinguishable from JSX tag boundaries by regex alone in
  a file that mixes JS and JSX. Replaced with a two-entry, file-scoped
  allowlist, the same pattern legacy scopecheck.py's own `KNOWN_OK` used for
  the identical problem.
- `csscheck.mjs`: a `used.add(...[arr])` typo (spreads a one-element array
  containing the split array, adding the array itself as a single Set
  member) produced ~150 garbage "class used with no CSS rule" lines before
  being caught and fixed to `arr.forEach(c => used.add(c))`.
- `deadcode.mjs`: initial port only checked top-level declarations, same
  scope as the monolith's checker — but the monolith had no component-local
  scope at all (one function, the whole app). Extended to also flag a
  `useMemo` value computed and never read again inside a component, which is
  what actually reproduces the routine's own claim that this checker "will
  find real things immediately" (the known `doseAdvice` dead memos are
  local, not top-level — the unextended port would have missed them).

Two real, live `ReferenceError` bugs surfaced during this work, independent
