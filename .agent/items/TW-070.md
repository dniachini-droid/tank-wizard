title: The steadiness panel grades the window the keeper selected, and names it
status: needs-approval

why: `wizard-states.md` §25.2, amended 2026-08-16 (Stage 5), and §22 with it.
§25.2 as first written fixed the panel's window per parameter at
`reef-chemistry.md` §4's analysis window — 14 days alkalinity, 28 calcium and
magnesium. The app offers 7 / 30 / 90 / All (`Dashboard.jsx:232-234`) and grades
whatever is picked. **The buttons stay; the panel grades the selection and names
it in the heading.**
the shape of the heading: *"Over the last 90 days — wide swing, 1.1 dKH between
highest and lowest."* The rule §25.2 exists to enforce is that a verdict says
what it judged, and a heading naming the selection satisfies it. Fixing the
window would have deleted a control the keeper uses in order to make a sentence
true, when the sentence can be made true instead.
what this does not touch: §4's analysis window is still what the wizard's
arithmetic runs on — consumption, dose gaps, §11's movement rule. Do not
re-point any of those at the panel's selection. The panel is a different
question over a different span, which is the whole basis of §22's second
vocabulary.
carried in with it and not resolved by this item: `sliding` renders as **"Moving
up/down fast"**, which is direction language on a panel §25.2 forbids direction
language on. The verdict word is untouched; the headline needs re-drafting and
that is owner copy, recorded at §22 and §25.2.
also open at G-12 and not this item's to settle: Insights uses its own default
of 90 days (`Insights.jsx:128`), and the panel's button set changes with test
cadence (7/30/90/All under a 3-day cadence, 30/90/180/All otherwise).
in plain terms: the steadiness panel already lets you pick 7, 30, 90 days or
everything, and it already grades what you picked — the spec had said it should
always grade a fixed window instead. The spec now agrees with the buttons, and
the panel has to say which window it is talking about at the top, so it can
never again disagree with the advice above it without you being able to see why.
spec: docs/spec/wizard-states.md §25.2 (rule 1 as amended), §22's panel bullet,
§13; docs/spec/reef-chemistry.md §4
repro: `Dashboard.jsx:232-234` offers four windows; §25.2 as written before this
amendment named one.
tests it needs: the heading states the selected window for each of the four
selections; the verdict is computed over that same span and not over §4's; and
no direction word appears in any panel string, which is TW-028's check extended.
